# Earth-K AstrBot 迁移版

这是 Earth-K-Plugin 的 AstrBot 原生迁移版本。命令统一使用 AstrBot 的 `/` 触发方式，不再使用 Yunzai 的 `#` 规则。

## 当前可用命令

- `/卜卦`：第一次发送说明规则，第二次发送生成卦象图片。
- `/土块帮助`：查看当前已迁移和迁移中的功能。
- `/土块版本`：查看迁移版本信息。
- `/土块渲染测试`：仅管理员私聊可用，验证本地 Playwright HTML 渲染。
- `/土块更新`：仅管理员可用，调用 AstrBot 官方插件更新器并自动重载。

## 渲染方式

原有 HTML、CSS、图片、字体和音频资源会继续复用。图片由插件内置的 Playwright 渲染器在本地生成，不调用 AstrBot 的 `html_render`，因此不会经过外部 `t2i` 服务。

## 迁移进度

第一批已完成原生 AstrBot 插件入口、本地资源路径、Playwright 渲染器和周易占卜。点歌、视频、小说、漫画、猜原神、猜语音、群小游戏、原史和 AI 绘图等功能会逐项替换 Yunzai 事件、消息段、配置和外部接口。

迁移完成前保留原 JavaScript 文件仅用于功能对照；AstrBot 只加载 `main.py`。
