# Earth-K AstrBot 迁移版

这是 [Earth-K-Plugin](https://github.com/SmallK111407/earth-k-plugin) 的 AstrBot 原生迁移版本。命令统一使用 AstrBot 的 `/` 触发方式，不再使用 Yunzai 的 `#` 规则。

## 当前可用命令

- `/卜卦`：第一次发送说明规则，第二次发送生成卦象图片。
- `/练习记忆力`：发送数字记忆卡，10 秒后发送字母卡，用 `/我猜 <字母>` 作答。
- `/重置记忆分数`：仅管理员可用，重置当前会话分数。
- `/今日运势`：优先使用在线服务，在线服务不可用时使用本地备用结果。
- `/测试智商`：随机发送一题本地脑筋急转弯。
- `/打我`：在群里发起猜拳；发送 `/石头`、`/剪刀` 或 `/布` 回答。
- `/打他 <用户ID>`：仅管理员可用，指定用户进行猜拳；`/挑选幸运儿` 随机选择当前群成员。
- `/发起你说我猜`、`/加入你说我猜`、`/开始你说我猜`：启动群内你说我猜。
- `/猜测 <答案>`：回答你说我猜或你画我猜；`/写答案 <答案>` 允许当前描述者自定义答案；`/结束你说我猜` 结束游戏。
- `/发起你画我猜`、`/加入你画我猜`、`/开始你画我猜`：启动群内你画我猜；当前画手私聊收题后在群里发送图片。
- `/结束你画我猜`：发起者结束游戏。
- `/发起故事接龙`、`/加入故事接龙`、`/开始故事接龙`：启动群内故事接龙。
- `/讲述 <内容>`：当前描述者续写故事；`/结束故事接龙`：发起者结束游戏。
- `/发起一站到底`、`/加入一站到底`、`/开始一站到底`：启动群内答题淘汰游戏。
- `/答 <答案>`：当前玩家回答题目；`/结束一站到底`：发起者结束游戏。
- `/了解 <角色>`：发送资源目录中已有的角色资料图。
- `/角色语音汇总`：查看可用的原神角色语音。
- `/语音 <角色> [编号]`：播放指定角色的中文语音；不填编号时随机播放。
- `/猜语音`、`/猜语音答案 <角色>`：开始并回答猜语音游戏；可用 `/公布语音答案` 结束当前回合。
- `/重置语音分数`：仅管理员可用，重置当前会话的猜语音分数。
- `/角色视频列表`、`/角色视频 <编号>`：查看并播放原神角色视频。
- `/过场动画列表`、`/过场动画 <编号>`：查看并播放原神过场动画。
- `/魔法目录`：查看本地绘图标签目录；`/目录 <名称或编号>`：查看标签内容。
- `/预览图 <名称>`：查看指定绘图标签的预览图。
- `/娶群友`：随机选择一名群友成为对象；`/强娶 <用户ID>` 和 `/抢群友 <用户ID>`：指定或尝试抢走对象。
- `/我对象呢`、`/闹离婚`、`/群对象列表`：查看、解除或渲染当前群的对象关系。
- `/原史 <名称>`：查询原神角色、武器、圣遗物、敌人等资料。
- `/原史目录 <分类>`：渲染指定分类的原神资料目录，例如 `/原史目录 角色`。
- `/猜原神`、`/猜原神答案 <名称>`：开始并回答本地题库猜原神游戏。
- `/猜原神提示`：获取当前题目的额外提示；`/公布原神答案` 结束当前回合。
- `/重置原神猜题分数`：仅管理员可用，重置当前会话分数。
- `/大话骰规则`：发送大话骰规则图片。
- `/发起大话骰`、`/加入大话骰`、`/开始大话骰`：在当前群聊开始游戏。
- `/我的骰子`：私聊机器人查看自己的骰子；`/叫骰 <数量> <点数>` 和 `/开蛊` 用于进行游戏。
- `/结束大话骰`：房主结束游戏。
- `/土块发电榜`（或 `/发电榜`）：查看发电排行；`/最近发电`：查看最近发电支持者。
- `/土块状态`：查看 AstrBot 宿主进程和系统状态图。
- `/弹琴帮助`：查看音频演奏说明。
- `/钢琴 <音符>`：使用本地音色演奏；也支持 `/八音盒`、`/古筝`、`/吉他`、`/萨克斯`、`/小提琴`、`/吹箫`、`/西域琴`。
- `/土块表情列表`：查看可用的表情合成关键词。
- `/表情合成 <关键词> [文字]`：使用当前命令附带的图片生成表情。
- `/土块帮助`：查看当前已迁移和迁移中的功能。
- `/土块版本`：查看迁移版本信息。
- `/土块渲染测试`：仅管理员私聊可用，验证本地 Playwright HTML 渲染。
- `/土块更新`：仅管理员可用，调用 AstrBot 官方插件更新器并自动重载。

## 渲染方式

原有 HTML、CSS、图片、字体和音频资源会继续复用。图片由插件内置的 Playwright 渲染器在本地生成，不调用 AstrBot 的 `html_render`，因此不会经过外部 `t2i` 服务。

原史资料使用 HoYoWiki 的公开接口，支持角色、武器、圣遗物、敌人、物产、NPC、书籍、教程和动物条目；不再依赖 Yunzai 的 `gsCfg` 或已失效的米游社旧 `content/info` 接口。

## 迁移进度

当前已完成原生 AstrBot 插件入口、本地资源路径、Playwright 渲染器、周易占卜、原神历史资料、角色语音与视频、猜原神、本地智商题、群内小游戏、故事接龙、魔法目录、发电榜等功能。点歌、小说、漫画、B 站视频和 AI 绘图按当前迁移范围暂不启用。

迁移完成前保留原 JavaScript 文件仅用于功能对照；AstrBot 只加载 `main.py`。
